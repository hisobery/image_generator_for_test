# image_generator_for_test
该.py脚本通过调用图像生成接口（gpt-image-2 模型），将文本提示词和可选的参考图片生成新图像，并将返回的图片自动下载保存到本地。主要步骤包括： 将本地参考图片读取并编码为 Base64 字符串； 组装请求体，指定模型、提示词、画面比例、质量等参数； 发送 POST 请求，解析 JSON 响应，提取生成图片的 URL； 下载图片并以 image_时间戳.png 格式保存到脚本同目录下的 generated_images 文件夹中。

## 配置与鉴权
- 通过url变量指定API服务端点，api_key填写访问密钥，并在请求头中以Bearer Token形式进行身份验证。

## 参考图片预处理（可选）
- 支持将本地图片作为生成参考，用户可在image_path列表中填入图片的绝对路径。脚本遍历该列表，将每张图片以二进制读入并编码为Base64字符串，存放于image_result中。若无需参考图片，保持列表为空即可。

## 生成请求构造
- 使用JSON格式的负载（payload）组织生成参数，包括：
  - model：指定使用的模型（如gpt-image-2）；
  - prompt：文本提示词，描述期望的图像内容；
  - aspect_ratio：输出画面的宽高比（如1:1）；
  - quality：生成质量（如high）；
  - image：携带前一步生成的Base64参考图列表。
- 所有参数打包后通过POST请求发送至API。

## 响应处理与容错
- 接收响应后执行多层校验：
  - 检查HTTP状态码，非200时打印错误详情并终止；
  - 验证响应体是否为合法JSON，失败则输出原始内容并退出；
  - 从解析后的JSON中提取data字段，若无图片数据（例如列表为空）则输出完整响应并终止；
  - 从第一张图片的数据中获取url，缺失时退出程序。
- 这些检查保证了在API异常或返回格式不符合预期时，能及时中断并提供清晰的错误信息。

## 图片下载与本地保存
- 自动创建与脚本同级的generated_images目录，如已存在则不重复创建；
- 从响应URL下载图片二进制数据，并智能处理文件扩展名：从URL路径中提取后缀，移除可能的查询参数，若获取失效则默认使用.png；
- 使用当前时间戳生成唯一文件名（如image_20260426_143021.png），避免覆盖旧文件；
- 将图片字节流写入目标路径，完成保存。若下载请求失败，也会打印对应状态码提示用户。
